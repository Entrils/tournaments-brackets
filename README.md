# Tournament Brackets

Веб-приложение для создания и проведения турниров с визуальной сеткой матчей.
https://entrilstourneyapp.netlify.app/ - тест

## Что реализовано

- Поддержка нескольких турниров.
- Три режима турнира:
- `Single elimination`.
- `Double elimination` (верхняя и нижняя сетки + grand final).
- `Group stage + playoffs`.
- Добавление, редактирование и удаление команд.
- Случайная генерация сетки.
- Выбор победителя каждого матча.
- Ручное редактирование результата матча (счет, техническое поражение).
- Запрос переигровки (сброс результата матча).
- Определение чемпиона и блокировка завершенного турнира.
- Сохранение состояния в `localStorage`.
- Базовые UI-тесты для главной страницы и страницы сетки.

## Стек

- React 18
- Redux
- React Router v6
- Bootstrap 5
- Jest + RTL

### Установка и запуск

```bash
npm install
npm start
```


## Как использовать

1. Создайте турнир на главной странице и выберите режим.
2. Добавьте минимум 2 команды.
3. Откройте страницу сетки и нажмите `Generate Bracket (Random)`.
4. Выбирайте победителей или используйте `Edit` для точного результата.
5. Используйте `Replay`, если матч нужно переиграть.
6. После определения чемпиона турнир становится read-only.
